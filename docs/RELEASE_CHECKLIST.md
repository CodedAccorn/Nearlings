# Release and hackathon submission checklist

- [ ] Recheck official NEAR hackathon page and HACKATHON.md; capture exact requirements and deadline.
- [ ] App runs from clean clone using README; .env.example has placeholders only.
- [ ] Automated tests, lint, typecheck, build and contract tests pass.
- [ ] Independent security/code review findings resolved or disclosed.
- [ ] Testnet contract and live app URL verified; no secrets in commits.
- [ ] Public GitHub repository includes license, architecture, setup, deployment, demo, limitations and evidence of NEAR integration.
- [ ] Publish demo post on X with required tags/hashtag per official rules; verify public URL.
- [ ] Submit required repository/demo URLs in official form before deadline; save confirmation.
- [ ] Do not claim unimplemented verification, sponsorship, autonomy or yield guarantees.
